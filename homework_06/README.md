# ДЗ 6

Ця директорія містить стартовий код для ДЗ 6 який перекочував з ДЗ 1. Весь код організована в одному файлі
main.cpp. Він розроблений в онлайн редакторі тому можливо не реалізований по стандартах C++. Але для нашої
задачі цього цілком достатньо. Тому реалізовуємо тут наступні задачі:
- CMake;
- тести через CTest;
- форматування;
- попередження компілятора;
- clang-tidy;
- здача змін через PR.

`CMakeLists.txt` необхідно створити як частину ДЗ:

- `src\main.cpp` - бібліотека з логікою читання, парсингу і підсумку;
- `homework_06` підключається у кореневому `CMakeLists.txt`.
